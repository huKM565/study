# ПР5 «Дискретное преобразование сигналов» — вариант 9

Исходные данные (таблица 5.1): Um1 = 9 В, Um2 = 5 В, F1 = 5 кГц, F2 = 9 кГц, φ01 = 10°, φ02 = 40°.

`u(t) = 9·cos(2π·5000·t + 10°) + 5·cos(2π·9000·t + 40°)`

- Fmax = 9 кГц → по Котельникову fд ≥ 2·Fmax = 18 кГц, Tд ≤ 1/(2·Fmax) ≈ 55,6 мкс.
- В программе fд = k·2Fmax, по умолчанию k = 1,25 → fд = 22,5 кГц, Tд ≈ 44,4 мкс, погрешность восстановления ≈ 0,0005 В.
- При k = 1 (ровно 2Fmax) отсчёты 9-килогерцовой составляющей попадают в одни и те же фазы, и её амплитуда теряется: погрешность ≈ 3,2 В. Поэтому на практике частоту дискретизации берут с запасом.
- При k < 1 возникает наложение спектров: восстанавливается совсем другой сигнал (при k = 0,8 погрешность ≈ 9,6 В).

## Контрольные вопросы

**1. Что называется дискретным сигналом?**

Сигнал, который задан только в отдельные моменты времени (отсчёты) и/или принимает только заранее определённые значения. Цифровой сигнал — дискретный и по времени, и по уровню.

**2. Что называется непрерывным сигналом?**

Сигнал, который существует в любой момент времени и может принимать любое значение в своём диапазоне (аналоговый). Пример — `u(t)` из задания.

**3. Что называется дискретизацией?**

Замена непрерывного сигнала последовательностью его мгновенных значений (отсчётов), взятых через равные промежутки времени `Tд`. Величина `fд = 1/Tд` — частота дискретизации.

**4. Что называется квантованием?**

Замена значений отсчётов ближайшими разрешёнными уровнями из конечного набора (дискретизация по уровню). После квантования каждый уровень можно закодировать двоичным числом. Вносит неустранимую ошибку квантования — не больше половины шага между уровнями.

**5. Как формулируется теорема Котельникова?**

Если спектр аналогового сигнала `x(t)` ограничен частотой `Fmax`, то сигнал можно восстановить с какой угодно точностью по его отсчётам, взятым с частотой `fд ≥ 2·Fmax` (с периодом `Tд ≤ 1/(2·Fmax)`). Восстановление — по ряду Котельникова:

    x(t) = Σ x(k·Δt) · sin(ωm·(t − k·Δt)) / (ωm·(t − k·Δt)),   ωm = 2π·Fmax

Если в сигнале есть частоты выше `fд/2`, восстановить его без искажений невозможно.
