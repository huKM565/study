# ПР3 «Оценка энтропийных характеристик» — вариант 9

## Контрольные вопросы

**1. Что называется энтропией?**

Энтропия — числовая характеристика, мера средней неопределённости источника: насколько сложно предсказать, какое сообщение он выдаст следующим. Измеряется в битах. Вычисляется по формуле Шеннона как сумма произведений вероятности каждого сообщения на количество информации в нём: `H = Σ p·I = −Σ p·log₂p`.

**2. Какие существуют виды энтропии для дискретной случайной величины?**

- **Безусловная** энтропия `H(X) = −Σ p(x)·log₂p(x)` — неопределённость самой величины X.
- **Условная** энтропия — неопределённость X, которая остаётся, когда известна другая величина Y.
  - Частная, при известном значении y: `H(X|y) = −Σ p(x|y)·log₂p(x|y)`.
  - Средняя, по всем значениям Y: `H(X|Y) = −ΣΣ p(x,y)·log₂p(x|y)`.
  - Условная энтропия не больше безусловной.
- **Совместная** энтропия двух величин — неопределённость пары (X, Y), рассматриваемой как одно сообщение. `H(XY) = H(X) + H(Y|X)`: угадать пару = угадать первое + доугадать второе при известном первом. Для независимых величин второй слагаемое не уменьшается и `H(XY) = H(X) + H(Y)` — информация просто складывается.
- **Максимальная** энтропия — когда все N значений равновероятны: `H = log₂N` (мера Хартли).

**3. Какие существуют виды энтропии для непрерывной случайной величины?**

- **Дифференциальная** `h(X) = −∫ p(x)·log₂p(x) dx` (p(x) — плотность вероятности). Прямой перенос формулы Шеннона: сумма → интеграл, вероятность → плотность. Не является «настоящей» энтропией в битах: может быть отрицательной, зависит от единиц измерения x. Используется как *относительная* характеристика — для сравнения источников между собой.
- **С шагом квантования** `H(X) = −∫ p(x)·log₂p(x) dx − log₂Δx = h(X) − log₂Δx`. Это честная энтропия, когда непрерывную величину разбили на корзины ширины Δx и свели к дискретному источнику. При Δx → 0 слагаемое `−log₂Δx` уходит в бесконечность — абсолютная энтропия непрерывной величины бесконечна, поэтому на практике и ограничиваются дифференциальной частью (постоянное `−log₂Δx` при сравнении двух источников сокращается).
- **Условная дифференциальная** `h(X|Y) = −∫∫ p(x,y)·log₂p(x|y) dx dy`. Та же логика, что у дискретной условной: неопределённость X, когда известна Y. Отличие от h(X) — вместо p(x) берётся условная плотность p(x|y), усреднение идёт по совместной p(x,y).

**4. Каким образом рассчитывается вероятностная мера неопределённости Шеннона?**

По формуле Шеннона: `H(X) = Σ p(xᵢ)·log₂(1/p(xᵢ)) = −Σ p(xᵢ)·log₂p(xᵢ)`. Здесь `log₂(1/p(xᵢ))` — мера неопределённости i-го значения, а H — её среднее с весами-вероятностями. Максимальна при равновероятных значениях и тогда равна `log₂N`.

**5. Каким образом рассчитывается относительная энтропия?**

Как отношение энтропии источника к максимально возможной: `h = H(X) / Hmax = H(X) / log₂N`. Показывает, насколько источник близок к равновероятному, от 0 до 1. С ней связана избыточность из ПР4: `R = 1 − H(X)/Hmax`.

## Обозначения

- **X** — исходный источник, три сообщения x₁, x₂, x₃ с вероятностями Px1, Px2, Px3.
- **Y** — тот же источник, но x₂ и x₃ склеены в одно: «первое или пара».
- **Z** — выбор внутри пары: x₂ или x₃, когда уже известно, что выпала пара.
- **p(x|y)** — условная вероятность: вероятность значения x, если уже известно значение y.
- **I(x|y) = −log₂p(x|y)** — неопределённость одного конкретного значения x при известном y.
- **H(X|y)** — неопределённость всей величины X при известном значении y (среднее I(x|y) по всем x).

## Формулы и числа варианта 9

Данные: `Px1 = 9/23`, `Px2 = 8/23`, `Px3 = 5/23`.

| Что | Формула | Вариант 9 |
|---|---|---|
| Вероятности X | `Px = (Px1, Px2, Px3)` | 9/23, 8/23, 5/23 |
| Вероятности Y | `Py = (Px1, Px2 + Px3)` | 9/23, 13/23 |
| Вероятности Z | `Pz = (Px2/(Px2 + Px3), Px3/(Px2 + Px3))` | 8/13, 5/13 |
| Энтропия X | `H(X) = −(Px1·log₂Px1 + Px2·log₂Px2 + Px3·log₂Px3)` | 1,5382 бит |
| Энтропия Y | `H(Y) = −(Px1·log₂Px1 + (Px2 + Px3)·log₂(Px2 + Px3))` | 0,9949 бит |
| Энтропия Z | `H(Z) = −(Px2/(Px2+Px3)·log₂(Px2/(Px2+Px3)) + Px3/(Px2+Px3)·log₂(Px3/(Px2+Px3)))` | 0,9612 бит |
| Связь | `H(X) = H(Y) + (Px2 + Px3)·H(Z)` | 0,9949 + 13/23 · 0,9612 = 1,5382 |

## Что важно помнить

- Связь энтропий: угадать одно из трёх = сначала угадать «первое или пара» (H(Y)), а потом, если выпала пара, угадать внутри неё (H(Z)). Второй шаг нужен не всегда, а с вероятностью пары `Px2 + Px3`, поэтому H(Z) умножается на неё. Это свойство группировки (аддитивности) энтропии.
- Почему `log₂(1/p)`: чем реже значение, тем оно неожиданнее и тем больше его неопределённость; `1/p` растёт, когда p падает. `log₂(1/p) = −log₂p`.
- Неопределённость значения до его получения и информация после получения — одно и то же число `−log₂p`.
- В варианте 9 вероятности в сумме дают 22/23, а не 1 — похоже на опечатку в методичке, у остальных вариантов сумма ровно 1. Программа считает с данными как есть.
